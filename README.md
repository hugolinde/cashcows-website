# cashcows-website

Statische website.

## Talen
De site is drietalig:
- Nederlands: `index.html`, `playlist.html`, `rider.html` (root)
- Engels: `en/`
- Spaans: `es/`

Pas je tekst of inhoud aan (bijv. een nieuwe video of foto)? Doe dat dan in alle drie de versies.
Teksten die het script zelf zet (Meer laden, Afspelen…) staan bovenaan `js/main.js`.
